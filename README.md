# Flight Status Dashboard 

## Overview

Flight Status Dashboard is a Power BI project designed to analyze airline operations and flight performance using interactive visualizations and data analytics techniques. The dashboard provides insights into flight delays, cancellations, airline efficiency, and passenger trends to support better operational decision-making.

## Dashboard Preview

The dashboard includes:

* Total Flights Analysis
* Delayed Flights Tracking
* Cancelled Flights Monitoring
* Airline-wise Delay Percentage
* City-wise Flight Distribution
* Cancellation Reason Analysis
* Day-wise Cancellation Trends
* Flight Status Distribution (On Time, Delayed, Cancelled)

## Key Insights

* Analyzed over **2 Million Flights**
* Identified delay and cancellation patterns across different airlines
* Compared airline performance using delay percentages
* Evaluated city-wise flight traffic
* Examined major cancellation reasons and weekly trends
